# 接口与协议

后端：FastAPI（`server/`），默认 `http://localhost:8000`，交互式文档 `/docs`。

数据存储：SQLite（`server/data/sansa.db`），首次启动自动建表。

---

## 1. REST

### 1.1 健康检查

```
GET /api/health
```

```json
{ "ok": true, "rooms": 4, "online": { "02": 3 } }
```

### 1.2 房间列表

```
GET /api/rooms
```

```json
{
  "items": [
    { "room": "01", "name": "山寺 01", "online": 0, "capacity": 20, "status": "open" },
    { "room": "02", "name": "山寺 02", "online": 3, "capacity": 20, "status": "open" }
  ],
  "capacity": 20
}
```

`status`：`open`（<70%）、`busy`（≥70%）、`full`（满员）。

### 1.3 单房间详情

```
GET /api/rooms/{room}
```

返回 `room`、`online`、`capacity`、`players[]`（id/name/x/z/ry）。

### 1.4 愿望灯

```
GET  /api/lanterns?room=02
POST /api/lanterns
```

GET 返回（含灯架布局，前端据此点亮钩位）：

```json
{
  "room": "02", "hooks": 24, "total": 3, "free": 21,
  "colors": ["jin", "zhu", "qing", "bai"],
  "items": [
    { "id": 1, "hook": 5, "color": "zhu", "wish": "愿母亲安康", "author": "", "created_at": "..." }
  ]
}
```

POST 体：

```json
{ "room": "02", "hook": 1, "color": "jin", "wish": "愿母亲安康", "author": "zcj" }
```

约束：
- `wish` 1–40 字（与原站一致）；
- `hook` 取 `0 .. LANTERN_HOOKS-1`（默认 0–23，3 层 × 8 钩），越界返回 **422**；
- 同一房间同一钩位唯一，冲突返回 **409**；
- `color`：`jin` 祈愿（暖金）、`zhu` 平安（朱）、`qing` 追思（青）、`bai` 无言（素）；
- 挂灯成功后向同房间广播 `lantern` 事件，在场的人立刻看到灯亮起。

### 1.5 功德

```
GET  /api/merit/{key}
POST /api/merit/{key}   { "delta": 1 }
```

`key` 约定：`bow`（拜数）、`beads`（念珠颗数）、`moktak`（木鱼声数）。

`bow` 超过 25 时返回 `coffee_unlocked: true`（原站以 25 拜解锁一杯咖啡）。

### 1.6 搬瓦

```
GET  /api/tiles
POST /api/tiles   { "room": "02", "delta": 1 }
```

`GET` 返回：

```json
{ "items": [{ "room": "02", "tiles": 8 }], "total": 8, "goal": 1080, "percent": 0.7 }
```

`goal` 由 `SANSA_TILE_GOAL` 控制（默认 1080 片 = 一座殿）。`percent` 已按 0–100 截断，前端直接用作进度条宽度与瓦堆高度。搬瓦成功后广播 `tile`。

### 1.7 上香排队

```
GET    /api/incense?room=02&token=xxx
POST   /api/incense    { "room": "02", "name": "访客" }
DELETE /api/incense?room=02&token=xxx
```

`GET` 返回：

```json
{
  "room": "02", "hold": 20, "size": 2,
  "current": { "name": "访客", "remain": 18 },
  "queue":   [{ "name": "访客", "wait": 18 }],
  "mine":    { "name": "访客", "position": 1, "wait": 0 }
}
```

规则：
- 队首即"正在上香"，`hold` 秒（默认 20，`SANSA_INCENSE_HOLD`）后自动出队，下一位从当前时刻重新计时；
- 计时**惰性推进**：所有状态在每次查询时结算，不需要后台定时任务；
- `token` 是入队凭证，用来算 `mine`（我在第几位、还要等多久）以及主动离队；
- `POST` 返回 `token` + 同一份状态（含 `mine`），前端一次拿全；
- 队列存在进程内存：重启即清空。上香是"人和香同时在场"的瞬时状态，落库只会留下无法唤醒的僵尸队列。多实例部署时把 `IncenseQueue.rooms` 换成 Redis List，语义不变。

### 1.8 供养

```
GET /api/support
```

```json
{ "bank": "招商银行 山寺 6225 **** **** 3721", "pay_qr": "", "note": "供养随喜，不拘多少。" }
```

银行信息与二维码可通过环境变量 `SANSA_BANK` / `SANSA_PAY_QR` 覆盖，避免硬编码。

## 2. WebSocket 在场同步

```
ws://localhost:8000/ws/presence?room=02&name=访客
```

- 每房间上限 20 人（`SANSA_ROOM_CAPACITY`）；
- 满员时先回 `{"t":"error","code":"full"}` 再以 4001 关闭；
- 服务端只转发，不裁决位置合法性。

### 2.1 客户端 → 服务端

| t | 字段 | 说明 |
|---|---|---|
| `move` | `x` `z` `ry` | 位置与朝向，建议 8–10Hz（前端已节流 125ms） |
| `act` | `a` | `bow` / `pray` / `moktak` / `beads` / `sit` |
| `chat` | `m` | 一句话，≤80 字（可选） |
| `hello` | `name` | 入房后补报昵称 |

### 2.2 服务端 → 客户端

| t | 说明 |
|---|---|
| `welcome` | `id`、`room`、`capacity`、`players[]`（**不含自己**） |
| `join` | 有人进入：`id` `name` `x` `z` `ry` |
| `left` | 有人离开：`id` |
| `move` | 他人移动：`id` `x` `z` `ry` |
| `act` | 他人动作：`id` `a` |
| `chat` | `id` `name` `m` |
| `count` | 当前在线人数 `n` |
| `error` | `code`：`full` / `bad_message` |
| `lantern` | 有人挂灯：`item`（整条灯记录）、`total` |
| `tile` | 有人搬瓦：`room` `room_tiles` `total` `goal` `percent` |
| `incense` | 上香队列变化：与 `GET /api/incense` 同构（不含 `mine`） |

### 2.3 时序

```
客户端 A                 服务端                  客户端 B
   | -- connect ----------> |                       |
   | <-- welcome(players) -- |                       |
   |                        | <---- connect -------- |
   | <---- join(B) --------- | ---- welcome([A]) ---> |
   | <---- count(2) -------- | ---- count(2) -------> |
   | ---- move(1.5,-2,0.8)-> | ---- move(B) --------> |
   | ---- act(bow) --------> | ---- act(bow) -------->|
   |                        | <---- close ----------- |
   | <---- left(B) --------- |                       |
```

### 2.4 自检

```bash
cd server
uvicorn app.main:app --port 8000 &
python scripts/ws_check.py
```

输出 `OK · 在场协议自检通过` 表示 join / move / act / error / left 全链路正常。

## 3. 配置项

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `SANSA_HOST` / `SANSA_PORT` | `0.0.0.0` / `8000` | 监听地址 |
| `SANSA_ROOM_COUNT` | `4` | 房间数（房号 01..N） |
| `SANSA_ROOM_CAPACITY` | `20` | 单房间上限 |
| `SANSA_DB` | `server/data/sansa.db` | SQLite 路径 |
| `SANSA_LANTERN_HOOKS` | `24` | 灯架钩位数（3 层 × 8） |
| `SANSA_INCENSE_HOLD` | `20` | 每人上香秒数 |
| `SANSA_TILE_GOAL` | `1080` | 修一座殿所需瓦数 |
| `SANSA_CORS` | `*` | 允许来源，逗号分隔 |
| `SANSA_BANK` / `SANSA_PAY_QR` | 内置示例 | 供养信息 |

## 4. 前端对接位置

| 位置 | 作用 |
|---|---|
| `prototype/src/net.js`、`web/src/pages/temple/scene/net.js` | WS 客户端（重连、节流、消息分发） |
| `stage.js` 中 `opt.wsHost` | 后端地址；默认取 `location.hostname:8000`，生产环境改成同域 `/ws/presence` 反向代理 |
| 页面 `?room=02` | 指定房号 |
| `?offline=1` | 关闭联网，纯单机 |
