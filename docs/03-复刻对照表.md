## 落差说明

1. **美术资产**：原站为手工 GLB + PBR 贴图（佛像、僧侣、猫、建筑构件）。本复刻为程序化几何，形体准确但细节密度低一档；替换路径已预留（`world.js` 中 `makeBuddha` / `makeHall` 可整体替换为 GLTF 加载）。
2. **音频**：原站使用心经录音与现场采样。本复刻用 WebAudio 合成木鱼/钟声，无版权风险，但缺少诵经声场。
3. **多人规模**：原站 Workers + Durable Object，可水平扩展；本实现单进程内存态，重启即清空在场，适合演示与小规模。
4. **待办优先级**：点灯 > 上香 > 搬瓦 > 房间切换 > PWA。
